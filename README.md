# AI Engineering Roadmap Lessons

Daily visual lessons from a **29-week** (203-day) AI engineering roadmap covering four roles — **AI engineer**, **AI architect**, **AI security engineer**, and **AI platform engineer** — plus a parallel general architecture track.

The plan runs **Mon 19 Oct 2026 – Sun 9 May 2027** (times in Asia/Kolkata). This repository currently publishes **Days 1–30** of 203 as both Markdown and self-contained HTML. New days are added here as they are written.

The capstone through-line is **Project Bastion**, a threat-modelled, multi-tenant AI agent platform built week by week.

- Full syllabus: [roadmap.md](roadmap.md)
- Browse the HTML lessons on GitHub Pages (once enabled): [lesson index](https://suganthikannan093-hue.github.io/ai-engineering-roadmap-lessons/)
